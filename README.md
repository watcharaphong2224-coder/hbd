## 🎭 ลำดับฉากที่แฟนจะได้เห็น

1. **หน้าส่งใจ** — ปุ่ม "💗 ส่งใจ" กดทีละครั้ง หัวใจลอยขึ้นไปเติมหัวใจใหญ่
   - แสดงข้อความหวาน ๆ สุ่มขึ้นมาทุกครั้งที่กด
   - กดครบ **29 ที (100%)** → หัวใจเต้น คอนเฟตติ → ค้าง 5 วิ → เฟดออกไปหน้าเค้ก
2. **หน้าเค้ก** — เค้ก 3 ชั้นพร้อมเทียน 3 เล่ม (ลายรูดชมพู ไฟเรืองแสง สตรอว์เบอร์รี)
   - กดที่เค้ก → เทียนดับพร้อมกัน พ่นควัน → **เพลงเริ่มเล่นอัตโนมัติ** + คอนเฟตติ
3. **ซองจดหมาย** — โผล่ขึ้นมาหลังเป่าเทียน
   - แตะซอง → ฝาผายออก + จางหาย → **การ์ดกระดาษสไลด์ขึ้นมาจากซอง**
   - ข้อความอวยพรเริ่มพิมพ์ทีละตัวอักษร
4. **สไลด์โชว์รูป** — 10 รูป กด ‹ › หรือปัดซ้ายขวาบนมือถือ มีตัวนับ "1 / 10"
5. **ซองจุ๊บ** — 3 ซอง ทุกซองเป็น "😚 จุ๊บเหม่ง 1 ที" พร้อมปุ่มเปิดที่น่ารัก

## 🛠️ แก้ไขเองได้ง่าย ๆ

เปิด `index.html` ด้วย Notepad / VS Code แล้วค้นหาข้อความนี้:

| อยากเปลี่ยน | ค้นหา |
|---|---|
| ข้อความอวยพร | `var MESSAGE =` |
| ข้อความหวานตอนกดส่งใจ | `var SWEET =` |
| ข้อความในซองจุ๊บ | `var ENVS =` |
| ชื่อแฟน | `สุขสันต์วันเกิดนะครับคนเก่งของเค้า` |
| จำนวนหัวใจที่ต้องกด | `HF_TOTAL = 29` |
| รูปในสไลด์โชว์ | `var PHOTOS =` |

> ⚠️ **ข้อความอวยพร** ขึ้นบรรทัดใหม่ด้วย `\n`
> ถ้าอยากให้ขึ้นบรรทัดใหม่เยอะ ใส่ `\n` ต่อท้าย

## 📝 ประวัติการแก้ (สรุป)

- เปลี่ยน YouTube → เพลงฝังในไฟล์ `music.mp3` เล่นอัตโนมัติหลังเป่าเทียน
- ลบระบบไมค์เป่าเทียน → เหลือกดเค้กอย่างเดียว
- หน้าส่งใจ: กดค้าง → เปลี่ยนเป็นปุ่ม 💗 ส่งใจ 29 ที แม่นยำ 100%
- ซองจุ๊บ: ลบรางวัลหลอก ทุกซองเป็น "จุ๊บเหม่ง"
- รูป: บีบอัด 16MB → 1.3MB เร็วขึ้นมาก เปลี่ยนรูป 2 ใบตามที่ขอ
- ชื่อ repo: `hbd` → `memories-of-love` พร้อม QR ใหม่
- เค้ก: ปรับให้สวยขึ้น (ลายเทียน ไฟเรืองแสง สตรอว์เบอร์รี จานพอร์ซเลน)
- เพิ่มซองจดหมาย → การ์ดสไลด์ขึ้นมาจากซอง
- ข้อความ: แก้คำผิด เพิ่ม "ขึ้นมาเสมอ" และซ่อนปุ่มเมื่อส่งใจครบ
